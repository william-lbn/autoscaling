# PG17 DSGA节点约束Linux归档

仅修正DSGA VM的Runner Pod构造。原代码把linux/arch作为独立required NodeSelectorTerm追加，Kubernetes将term按OR解释，原hostname/区域约束可以被绕过。现在把linux/目标架构分别AND到每个原非空term，不新增OR分支，并深拷贝输入。

明确空selector/空term继续不匹配任何节点；原MatchFields、反亲和及NodeSelector保留。普通未启用DSGA的VM沿用原路径；没有扩展本轮独立CPU功能。

本次部署名单117/118/119由可信冻结配置提供，不由控制器硬编码或临时猜测。测试故意给116相同pool标签，仍须因hostname不在名单而拒绝；OS/架构不符也拒绝。
