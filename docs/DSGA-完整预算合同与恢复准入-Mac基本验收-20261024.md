# 完整预算合同与最终恢复准入：Mac基本验收

## 本批实际实现与边界

Agent原PGWorker现在消费同一journal的ResumeAdmission，不再将该步骤一律交ExternalStep。它只消费已存在且前序完成的操作，不自动Begin、不跳预算/Guest/VM步骤。真实预算/Host/Guest/VM约束生产者、独立初始启动准入、公开worker、最终VM执行/操作终结及跨boot/跨owner关闭恢复仍未完整接线，不能把本合同校验写成全功能完成或仅Linux待验。

budget.Finalized要求原完整请求、原issuer、同PG boot/容量/完整原生提交、原Runner名称/重启次数、Host承诺引用和实际VM内存读回。Guest可用容量不得超过实际VM目标。所有数值checked求和，采样/estimate/memory.high不能替代硬上限或持久已承诺上界；source引用须独立。kind/SourceID格式本身不认证或执行约束，生产者必须在真实约束与回读完成后才能写FinalizeBudget完成事实。

支持两种互斥的去重模型：分类模式为PG固定主段+当前DSG数组，再加OS/非PG、私有+DSM、LFC外部、Guest巨页池未计部分、变配开销、安全余量；聚合模式以整个PG主段/DSG/私有/DSM/LFC和整个Guest HugeTLB池的聚合上界计一次，再加不在覆盖范围内的系统/变配/安全项。聚合时私有/LFC/外部池三项必须省略，Shared只检验容纳能力，不再次相加。生产者可核验聚合硬约束，不能把全PG memory.max直接当私有上限叠加，也不要求强行拆出操作系统不提供的独立私有硬限额。

## 执行与恢复不变量

1. Session在调用前和取凭据时核验真实Lease/journal，使用原长期Client。当前PG floor必须Fenced，当前共享成本不可早于该隔离事实。
2. 只有前序完成、预算原生提交/完整分类与当前Runner/实际内存核对通过，才构造下一准入revision。先按固定VM UID/RV持久Start，返回真实票据后才发送完整setter。新开放不能跨旧resize未知。
3. 丢回复/写前提交回复丢失后按journal完整原意图只读查询，不改revision/预算/boot，不因not_found/淘汰/冲突自动重发。重建Worker显式恢复原准入pending，不能重建空Client绕过未知。
4. 确认原开放回执后再次核对返回快照的实际数组上界仍在原保留预算内，再记录ResumeAdmission完成。budget和PG仍无VM许可，异常不记录NoEffect。
5. 原意图重放有独立ReplayAdmissionOriginal及受信AdmissionReplay通道，只限当前owner、同boot已派发原意图且无abort，重查全预算后重放同值。普通轮询/错误不自动投递；与PG resize重放分开。跨owner不重放旧写，后续受控关闭/cleanup仍需接齐。

资源上界必须持续到显式对账/替换，不得随Agent租约到期自动解除。新PG boot不能解释为旧QMP/Guest动作失效。当前恢复仍保留旧resize未知；显式PG对账/跨owner关闭及完整资源持久协调不能靠丢弃HWM/journal代替。

## Mac必要验证与诚实证据

新增预算合同校验一项（含分类/聚合、禁止重计/估计/缺项/漂移等）；真实生产Owner/PGWorker+TLS消费者+既有Lease/RFC6902协议夹具的三条新增路径：setter回复丢失后重建只读确认、写前记录回复丢失不派发/不自动重发并允许显式原意图重放、预算不完整拒绝Start。最终该范围5个pass事件（含父用例），0fail/skip。受影响既有worker循环/租约取消/凭据期限/未知保护/关闭通道等另10个pass事件，0fail/skip；与其他运行重叠不累加。相关四包及Agent vet通过。

前序预算/VM完成值是明确协议夹具，不能声称已运行真实预算生产者、apiserver或NeonVM。严格原生PG/SQL/Router只在Neon成本模块单独执行。初轮对实现UnmarshalJSON的类型误用UnmarshalObject被递归防护拒绝，已改用json.Unmarshal进入类型自身strict alias解码，未放宽协议；初轮失败保留。

日志：build/dsga-final-admission-go-mac（初轮）、debug2（诊断）、fixed3、final4、response6、accounting7（最终预算/准入范围）、affected5（既有worker影响范围）。基本复现：go test -race -count=1 ./pkg/dsga/budget ./pkg/dsga/owner -run '^Test(FinalizedBudget|PGWorkerFinalAdmission)'。不重复无关功能。
