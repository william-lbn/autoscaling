# 部分容量取消：实际预算合同与来源读取

本批继续自有`codex/dsga-autoscaling-20261019`，准确代码及8个Go文件摘要见
[机器收据](DSGA-部分容量预算合同与来源读取-Mac收据-20261028.json)。本批是
部分效果取消所需的领域底座，**尚未完成永久预算替换、自动Cleanup/准入恢复
和最终Host结清接线**，不得将合同测试称为整个取消路径已经完成。

## 实际问题和合同

原Finalized以原目标全部成功为前提。在VM已变大而PG未扩时，或者PG/Guest已
缩而VM未缩时，修改原请求目标、沿用旧完整预算、伪造新目标成功都会造成账实
混淆。本批新增独立ReconciledCapacity，保留原Request，分别记录实际Buffer、
PG容量代次/原操作、当前VM容量、Root聚合/完整摘要、Outside和Host原来源。
旧Finalized严格解码拒绝此新结构；没有修改普通成功合同以兼容部分成功。

PG必须是同boot稳定前缀、已终止操作且分配已知；仅接受原expected或确切的
expected+1提交，后一种必须为本请求真实COMMITTED及原目标Buffer。当前成本
允许实际释放后下降，不允许超过保留上界；新的原操作、容量代次或floor不符
均拒绝。保存PG容量事实而非篡改原生Shared回复中的门禁/owner字段。

Outside来源的原VM目标必须准确等于当前实际VM：缩容取消后VM仍大，不能拿
小VM的系统资格覆盖大Guest的内核/系统成本。Host仍覆盖原before/目标/实际的
完整峰值及开销，来源保持直到显式结清。所有乘加、源去重和总预算均检查；
Root normal与整个HugeTLB池组成聚合，不能把包含巨页的Shared再全部压入
normal memory.max而重复计费。Root实际读回、内核计费和系统资格仍须认证。

Cleanup命令/审计分离：命令固定实际预算和原Prepare摘要，nullable Admission
为nil时只确认当前已开放；开放命令必须同实际PG代次/预算/原派发者。审计核
原Fence/Shared/Root/准入完整回复，普通查询不能伪装执行，较新门禁不算原
开放成功。合同不自己产生服务开放授权，未知仍需原查询或显式原重放。

## Runner及Host/Outside读取

NativeCapacity明确区分Completed的target与cancelled_before_send的before。
普通not_sent、may_have_sent、当前数字相等均不产生结清来源。实际Runner
读者核原不可变回执、完整原命令/外层WAL摘要、原Birth/State/owner floor及
当前实际值；同一回执不能改成另一种结果。普通CheckRetained保持原严格语义。
Grow原VM命令本来没有Guest前驱摘要，新读者只对该字段接受准确空值；其他
必需摘要和Shrink Guest摘要仍严格核验。

ReadReconciled只接受原Active取消；逐项读原immutable/protected CM UID、
VM owner、原运行Pod/Node，再由Node真实账本核同一Host CM发布和原完整计划。
重读核UID/RV/body，不拿相同target掩盖不同before。它只返回当前读取副本，
没有派发或释放权，不修改预算/CM/VM。当前预算关闭后的永久读取仍须后续接线。

没有新增网络锁；读取不能缓存成许可，生产协调器仍须在Start/发送/Record/
Finish前后复核来源，并用原VM UID/RV CAS线性化。失败保留原峰值和未知，
不自动缩回VM、regrow PG、清账或覆盖运维关闭。关键源码均有中文边界说明。

## 后续接线标准

永久当前预算须显式区分正常Finalized与实际ReconciledCapacity；原Cleanup
完整落账和长期持有必须同CAS，不能改写原计划/目标或只依赖16条历史。Host
结清须使用实际VM而非原目标，且继续核原Runner/Outside/Root；旧读者必须拒绝
新增持久语义。恢复开放需可信服务选择，原unknown恢复同一SDK pending。

后续必须完成这些真实接线，并在实际Agent组合覆盖部分状态、丢回复/接管、
历史淘汰、Host结清及再操作；本批不据这些设计要求宣称实现或E2E已通过。
可信Prepare/首次normal预算与开放、异常启动/跨boot/迁移、全部写者/CPU和
Monitor/策略继续。Linux K8s/NeonVM/KVM/cgroup/HugeTLB/真实物理释放、内核
残留和性能长稳未验，Mac协议夹具不代替目标平台认证。
