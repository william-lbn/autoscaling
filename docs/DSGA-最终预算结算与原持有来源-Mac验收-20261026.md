# 最终预算结算与持续持有来源：Mac验收

日期：2026-10-26。原autoscaling功能分支，基础e3641392。本模块是Finalize生产执行及
最终准入接线，**不是完整预算生产者已完成**。可信Prepare/剩余系统上界/Host-QMP
生产者、首次开放、安全降normal/私有后台及完整公开生命周期/跨boot仍需代码。

## 原步骤与真实读路径

实际Agent改用NewProductionPGWorker，必须有同一原root和可信CoreV1客户端；
不回落旧无持有来源路径。现有底层NewPGWorker保留模块/历史兼容，不能消费带新
Sources而没有持有对象读者的新结算；生产路径对无Sources的旧结算拒绝新开放。
旧未知准入先只读原状态，再检来源，不能隐藏已发送的效果或提前清外层WAL。

Finalize只处理既有操作，严格读取Completed Prepare、原GuestReady v2完整审计、
ResizePG和最终VM回执；Guest审计命令必须等于原WAL命令、当前RootAggregate仍是
原来源、真实PG出生/限额/floor一致。Shrink还要求原ObserveVM与ResizeVM准确body
相同，当前四数组物理release回执由Prepared.ValidateCurrent复核；Grow的VM发生在
未来GuestReady前，VM回执不得补造未来PG资源来源，最终结算再独立核真实Root源。

预算来源由原OutsideClaim和HostClaim的真实UID固定。只用可信Kube API，GET原
namespace的immutable ConfigMap，核单一reservation.json、类型标签、VM ownerref、
BlockOwnerDeletion和保护finalizer；原Pod UID/IP/Node/存活与真实Node UID另读。
Host须覆盖目标Guest内存加显式非零VMM/Host开销，乘加不溢出；不从spec PATCH、
当前RSS或一个NoPending声明生成Host/VM完成。

持有对象必须持续到显式结清，无TTL/租约过期释放；保护finalizer阻止VM GC抢先
删除。普通Agent只读，绝不创建、修改、删除承诺或移除finalizer。只有对应可信
生产者核验完整关闭后方可解除保护。标签/immutable/JSON/资格ID不是认证或上界
证明；RBAC、真实资格/资源约束和Host持有协议必须由生产者落实。缺生产者就阻断，
不能临时创建一份相同数字的ConfigMap当作已覆盖SystemOutsidePG。

## WAL、取消与丢回复

完整原Finalized和前驱摘要先经同一VM UID/RV CAS写入FinalizeBudget Unconfirmed，
CAS票据返回前不落完成。之后再次读持有对象/root/真实PG出生/PG成本与原VM版本，
才以完整Finalized记Completed。这里没有资源/Host/QMP写，重建只重复只读复核和
原CAS结算，不能更换命令、来源、epoch或重发PG resize。新owner不能Start旧操作，
但原未知结算保持只读可达，原请求epoch不被当前floor覆盖；实际跨owner的完整
生产集成尚未在本批验证。取消/期限不自动释放原承诺，完整受控关闭另行实现。

最终准入前/写后继续核同一Outside/Host对象和最终VM回执摘要，来源丢失/重建/
开始删除/保护被移除均拒绝完成。Setter已发送后失败保留原准入Unknown及预算，
不能由此猜NoEffect，也不自动重发开放或另发关闭。
