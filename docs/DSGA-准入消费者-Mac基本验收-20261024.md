# PG17 准入消费者：Mac 基本验收

本批实现准入完整意图/回执与真实 Neon HTTP 消费者，不等于整个在线内存伸缩已完成。功能分支沿用 `codex/dsga-autoscaling-20261019`，仅推自有 fork；官方 main 本轮 fresh fetch 后仍为 a4bce09e4d6bd7932ea634a1ed79afe26a9cfd1f，完整祖先关系缺失数为 0。

## 实现约定

- `AdmissionRequest` 与原生 PG/Neon SQL 严格对应七字段，拒绝重复/缺失/未知/null/大小写变体与有损 uint64。准入 revision 独立于 resize；预算引用不是预算完成证明。
- 回执核验完整原请求、实际绑定 boot、PG jsonb_out SHA256、动作和当前事实。更高 owner 可只读原回执；未见/淘汰、普通 memory、floor 推进均不能证明未执行。
- Go SDK 设置/查询/显式更高关闭/关闭查询使用固定 HTTPS、独立观察连接池，沿用短期凭据、不重定向、不透明重试和有界 JSON。关闭可在 resize 阻塞时到达；开放和新 resize 拒绝越过未确认意图。网络期间不持本地 mutex；panic/超时不自动丢失原意图。
- Config 显式恢复 `AdmissionPending` 和可选 `AdmissionClose` 的值副本；禁止初始发现擦除历史。关闭成功只解除本地未来门禁写栅栏，`prior_may_have_applied` 恒 true，`vm_shrink_permit` 恒 false；旧工作排空和预算撤销由外层另外确认。
- 当前SDK同一未知关闭意图必须保持不可变；其回执若已被其他更高写入淘汰，需要外层持久协调协议进一步处理，不能重建空客户端绕过。实际 Agent 持久准入/预算流程仍待接线。

## 必要验证与范围

Mac Go `-race` 定向测试：新增严格协议/回执、丢回复后恢复和完整关闭校验，以及受影响旧 resize PG 摘要向量共 3 项通过，0 fail/skip；新增 PG 准入摘要向量独立 1 项通过。`go vet` 两个受影响包通过。新两种 bool/ASCII 转义/uint64 高位向量来自准确 PG17 b144a23b2beae7e6d214c094121bf4bbfe13cd3d 的 jsonb_out+sha256，Neon Rust 使用同字节向量。测试日志：工作区 `build/dsga-admission-go-mac`、`build/dsga-admission-go-vector-mac`、`build/dsga-admission-context-vectors`。未重复无关套件。

复现：`go test -race -count=1 ./pkg/api/dsga ./pkg/dsga/compute -run '^Test(Admission|ContextDigestMatchesNativePGCanonicalVectors)'`。TLS 服务是明确的消费者协议夹具；真实 Router→SQL→PG 的基本用例在 Neon 分支，不冒充 K8s 或完整 Agent journal 端到端。

Linux K8s 后验：真实 RBAC/Service/证书与租约切换、NeonVM/KVM/内存热插拔、HugeTLB/物理释放、迁移/故障/性能长稳。尚缺真实 Agent 全预算/排空/启动准入、公开创建 worker 及最终 VM 完成链等业务接线，不能把它们列成仅待平台测试。暂不构建镜像、不部署、不合并主分支。
